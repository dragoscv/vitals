## Everyone who has contributed

Every person whose work lands in Vitals is credited here — code,
translations, documentation, bug reports that led to a fix, and design.

The list of code contributors is generated from the git history with
`git shortlog -sn`, listing names only. Automated and bot identities are not
listed. At the time of writing, the maintainer is the only human contributor.

## How to get listed

- **Code, documentation or translations:** your name is added when your pull
  request is merged. Commits must carry a Developer Certificate of Origin
  sign-off (`git commit -s`); see [CONTRIBUTING.md](CONTRIBUTING.md).
- **Other contributions** (a report that led to a fix, testing on unusual
  hardware, design work): open a pull request adding yourself below, with a
  link to the issue or discussion.

If you would prefer not to be listed, or want your name shown differently,
say so in your pull request or write to
[dragoscv12@gmail.com](mailto:dragoscv12@gmail.com).
