---
title: Changelog
description: Where to find what changed in each Vitals release.
---

Every notable change is recorded in
[`CHANGELOG.md`](https://github.com/dragoscv/vitals/blob/main/CHANGELOG.md) in the repository,
grouped by version.

Each published version also has its own page on
[GitHub Releases](https://github.com/dragoscv/vitals/releases), with the installers, the
`SHA256SUMS.txt` checksums and the release notes. The
[latest release](https://github.com/dragoscv/vitals/releases/latest) is always one link away.

Vitals follows [semantic versioning](https://semver.org). While the version starts with `0.`, a
minor release may still change behaviour; the changelog says so when it does.
