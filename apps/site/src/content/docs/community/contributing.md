Vitals is built in the open at [github.com/dragoscv/vitals](https://github.com/dragoscv/vitals),
and contributions are welcome.

## Report a problem

[Open an issue](https://github.com/dragoscv/vitals/issues/new/choose). Include your Windows version,
the Vitals version from **Settings → About**, and, if you can, the log files described in
[Troubleshooting](/guides/troubleshooting/#logs). The **Copy** button in **Why is my PC slow?**
produces a report that is often enough on its own.

## Send a change

Read [`CONTRIBUTING.md`](https://github.com/dragoscv/vitals/blob/main/CONTRIBUTING.md) first. It
covers building from source, the checks every change must pass, and the conventions the code
follows.

- **Sign off your commits.** The project uses the
  [Developer Certificate of Origin](https://developercertificate.org). Add `-s` to `git commit` so
  each commit carries a `Signed-off-by` line certifying you have the right to submit it.
- **Conventional commit messages**, such as `fix(processes): keep the selection when a row moves`.
- **Every user-facing string in both English and Romanian.**

## Code of conduct

Everyone taking part is expected to follow the
[code of conduct](https://github.com/dragoscv/vitals/blob/main/CODE_OF_CONDUCT.md).

## Security issues

Do not open a public issue for a vulnerability. Report it privately through
[GitHub security advisories](https://github.com/dragoscv/vitals/security/advisories/new). The
threat model and what is in scope are in
[`SECURITY.md`](https://github.com/dragoscv/vitals/blob/main/SECURITY.md).
