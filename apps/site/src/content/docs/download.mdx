## Ways to install

1. **Microsoft Store** — [Vitals: System Monitor](https://apps.microsoft.com/detail/9P95RK5VMGPJ).
   No SmartScreen warning, and the Store keeps it updated. The Store build leaves out the built-in
   updater, the Task Manager replacement and the optional sensors service.
2. **winget** — `winget install Vitals.Vitals`
3. **Scoop** — `scoop bucket add vitals https://github.com/dragoscv/scoop-vitals`, then
   `scoop install vitals/vitals`
4. **Installer** — the files below. SmartScreen warns on first run; [see why](#windows-smartscreen).
5. **Chocolatey** — `choco install vitals`. The 1.0 package is pending moderation; until it is
   approved only an old 0.9 pre-release is listed.

winget and Scoop update with every release automatically.

## Phone, watch and TV

Every [GitHub release](https://github.com/dragoscv/vitals/releases/latest) carries three Android
APKs: `Vitals_<version>_android.apk` for phones, `_wear.apk` for Wear OS and `_tv.apk` for Android
and Google TV. Each monitors the device it runs on and can watch paired Windows PCs on your local
network. Android asks you to allow installs from your browser or file manager the first time.
Google Play listings are coming later.

The iPhone app, **Vitals: System Monitor**, watches paired PCs and Macs on your local network. It
is in Apple's review; the App Store link appears here once it is approved.

## macOS

The disk image is signed with a Developer ID and notarised by Apple, so it opens without a warning.
Drag Vitals to Applications. It reads processor, memory, swap, disks, network, temperatures and
every process of your user, and can end, pause or reprioritise them. Readings a Mac does not report
— committed memory, per-process graphics use — show as a dash, never as zero.

## System requirements

- Windows 10 version 1809 or later, or Windows 11.
- An x64 or ARM64 processor.
- Microsoft Edge WebView2. It ships with Windows 11 and current Windows 10; the installer adds it
  automatically if it is missing.

## Verify the download

Every release is built by a public GitHub Actions workflow and carries a signed build
attestation. With the [GitHub CLI](https://cli.github.com) installed:

```powershell
gh attestation verify .\Vitals_x64-setup.exe --repo dragoscv/vitals
```

A successful result proves the file was built from this repository by its release workflow, and
names the exact commit. To compare checksums instead:

```powershell
Get-FileHash .\Vitals_x64-setup.exe -Algorithm SHA256
```

and look for the same value in `SHA256SUMS.txt`.

## Windows SmartScreen

The first time you run the installer, Windows may show **"Windows protected your PC"**. That is
expected.

- **Why:** the installer is not signed with a commercial code-signing certificate. Those cost
  several hundred euros a year, and SmartScreen trusts a file only after many people have run it.
  An unknown publisher is warned about by default.
- **What to do:** select **More info**, then **Run anyway**.
- **How to be sure it is safe:** verify the attestation or checksum above before you run it. That
  is a stronger guarantee than a certificate, because it ties the file to the public source code
  that produced it.

## Silent install

The installer asks one question: install for you only, or for everyone on this PC. To script it:

```powershell
.\Vitals_x64-setup.exe /S /CurrentUser
```

`/CurrentUser` installs to `%LOCALAPPDATA%\Programs\Vitals` with no administrator prompt.
`/AllUsers` installs to `Program Files` for everyone and needs administrator rights.

## Updates

The installer build checks for a new version in the background shortly after it starts. When one
is found it is downloaded, its signature is verified, and it is installed when you quit the app, or after ten minutes away from the PC while Vitals is only in the tray. It is never started while Windows is restarting or signing you out, which would cut the setup off.
An update with a missing or wrong signature is refused. You can turn the check off in
**Settings → About**. The Microsoft Store build is updated by the Store instead.

Installed for you only, an update needs no administrator approval. Installed for everyone, Windows
asks an administrator to approve each update, so Vitals does not install it on quit, where nobody
would see the prompt. Choose **Restart to update** in **Settings → About** or in the tray menu
instead. Copies installed by Vitals 1.0.3 or earlier move to a per-user install on their next
update, and **Settings → About** then offers to remove the old copy in `Program Files`.

## Uninstall

Open **Settings → Apps → Installed apps** in Windows, find **Vitals** and choose **Uninstall**.
Your settings and history in `%LOCALAPPDATA%\Vitals` are kept, so a reinstall picks up where you
left off. Delete that folder to remove them too.
