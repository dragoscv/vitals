## Variante de instalare

1. **Microsoft Store** — [Vitals: System Monitor](https://apps.microsoft.com/detail/9P95RK5VMGPJ).
   Fără avertisment SmartScreen, iar Store-ul îl ține la zi. Versiunea din Store nu are actualizarea
   automată proprie, înlocuirea Task Manager și serviciul opțional de senzori.
2. **winget** — `winget install Vitals.Vitals`
3. **Scoop** — `scoop bucket add vitals https://github.com/dragoscv/scoop-vitals`, apoi
   `scoop install vitals/vitals`
4. **Program de instalare** — fișierele de mai jos. SmartScreen avertizează la prima rulare;
   [vezi de ce](#windows-smartscreen).
5. **Chocolatey** — `choco install vitals`. Pachetul 1.0 așteaptă moderarea; până la aprobare este
   listată doar o versiune preliminară veche, 0.9.

winget și Scoop se actualizează automat la fiecare versiune.

## Telefon, ceas și televizor

Fiecare [versiune de pe GitHub](https://github.com/dragoscv/vitals/releases/latest) are trei fișiere
APK pentru Android: `Vitals_<versiune>_android.apk` pentru telefoane, `_wear.apk` pentru Wear OS și
`_tv.apk` pentru Android TV și Google TV. Fiecare monitorizează dispozitivul pe care rulează și poate
urmări PC-urile Windows asociate din rețeaua locală. Prima dată, Android îți cere să permiți
instalarea din browser sau din managerul de fișiere. Listările din Google Play urmează mai târziu.

## Cerințe de sistem

- Windows 10 versiunea 1809 sau mai nouă, ori Windows 11.
- Un procesor x64 sau ARM64.
- Microsoft Edge WebView2. Vine cu Windows 11 și cu versiunile actuale de Windows 10; dacă lipsește,
  programul de instalare îl adaugă automat.

## Verifică descărcarea

Fiecare versiune este construită de un flux de lucru GitHub Actions public și are o atestare de
build semnată. Cu [GitHub CLI](https://cli.github.com) instalat:

```powershell
gh attestation verify .\Vitals_x64-setup.exe --repo dragoscv/vitals
```

Un rezultat reușit dovedește că fișierul a fost construit din acest depozit de fluxul său de
lansare și numește commit-ul exact. Ca să compari sumele de control:

```powershell
Get-FileHash .\Vitals_x64-setup.exe -Algorithm SHA256
```

și caută aceeași valoare în `SHA256SUMS.txt`.

## Windows SmartScreen

La prima rulare a programului de instalare, Windows poate afișa **„Windows a protejat PC-ul”**.
Este de așteptat.

- **De ce:** programul de instalare nu este semnat cu un certificat comercial de semnare a codului.
  Acestea costă câteva sute de euro pe an, iar SmartScreen are încredere într-un fișier doar după ce
  l-au rulat mulți oameni. Un editor necunoscut primește implicit un avertisment.
- **Ce faci:** alege **Mai multe informații**, apoi **Rulează oricum**.
- **Cum te asiguri că este sigur:** verifică atestarea sau suma de control de mai sus înainte să îl
  rulezi. Este o garanție mai puternică decât un certificat, pentru că leagă fișierul de codul sursă
  public care l-a produs.

## Instalare silențioasă

Programul de instalare nu pune întrebări. Pentru scripturi:

```powershell
.\Vitals_x64-setup.exe /S
```

## Actualizări

Versiunea din programul de instalare verifică în fundal dacă există o versiune nouă, la scurt timp
după pornire. Când găsește una, o descarcă, îi verifică semnătura și o instalează când închizi
aplicația. O actualizare cu semnătură lipsă sau greșită este refuzată. Poți dezactiva verificarea
din **Setări → Despre**. Versiunea din Microsoft Store este actualizată de Store.

## Dezinstalare

Deschide în Windows **Setări → Aplicații → Aplicații instalate**, găsește **Vitals** și alege
**Dezinstalare**. Setările și istoricul din `%LOCALAPPDATA%\Vitals` sunt păstrate, așa că o
reinstalare continuă de unde ai rămas. Șterge acel folder ca să le elimini și pe ele.
