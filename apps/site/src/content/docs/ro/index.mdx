  </Card>
  <Card title="De ce merge greu calculatorul?" icon="magnifier">
    Un singur clic corelează procesorul, discul, presiunea pe memorie, rețeaua și limitarea termică,
    apoi numește cauza pe înțeles: un verdict, vinovații și un minut de grafic pe care îl poți copia
    într-un raport de eroare.
  </Card>
  <Card title="Procese cu model de risc" icon="list-format">
    Grupate, căutabile și stabile sub cursor. Oprirea, suspendarea și reluarea îți spun consecința
    reală înainte să confirmi, iar procesele care trăiesc sub o secundă sunt totuși înregistrate.
  </Card>
  <Card title="Performanță, completă" icon="laptop">
    Procesorul cu câte o celulă pentru fiecare nucleu logic, memoria, placa video, fiecare disc și
    adaptor de rețea, plus o filă Temperaturi care arată și ce nu poate măsura și de ce.
  </Card>
  <Card title="Dincolo de fereastră" icon="puzzle">
    Telefonul prin rețeaua locală, Prometheus, Home Assistant, un SDK TypeScript tipizat și o linie
    de comandă, toate alimentate de același eșantionator, deci arată mereu aceleași cifre.
  </Card>
  <Card title="Ușor pentru calculator" icon="rocket">
    Eșantionatorul Windows are un buget de 30 ms pe eșantion, impus în CI — cel mult circa 3 %
    dintr-un nucleu la ritmul de o secundă cât fereastra e vizibilă — și eșantionează doar o dată la
    20 de secunde când e ascunsă. Un monitor care apare printre cei mai mari consumatori în propria
    listă de procese și-a ratat rostul.
  </Card>
  <Card title="Zero telemetrie" icon="information">
    Fără statistici, fără raportare de erori, fără cont. Singura cerere automată este verificarea

  <Card title="Open source" icon="github">

## Instalare

<Tabs syncKey="install">
  <TabItem label="Microsoft Store">
    Ia [Vitals: System Monitor](https://apps.microsoft.com/detail/9P95RK5VMGPJ) din Microsoft Store.
    Nu apare niciun avertisment SmartScreen, iar Store-ul îl ține la zi. Versiunea din Store nu are
    actualizarea automată proprie, înlocuirea Task Manager și serviciul opțional de senzori.
  </TabItem>
  <TabItem label="winget">
    ```powershell
    winget install Vitals.Vitals
    ```
  </TabItem>
  <TabItem label="Scoop">
    ```powershell
    scoop bucket add vitals https://github.com/dragoscv/scoop-vitals
    scoop install vitals/vitals
    ```
  </TabItem>
  <TabItem label="Program de instalare">
    Descarcă [`Vitals_x64-setup.exe`](https://github.com/dragoscv/vitals/releases/latest/download/Vitals_x64-setup.exe)
    și rulează-l. Nu are expert de instalare. La prima rulare, Windows SmartScreen te va avertiza,
    pentru că programul nu este semnat cu un certificat
    comercial. [Pagina de descărcare](/ro/download/) explică de ce și cum verifici singur fișierul.
  </TabItem>
  <TabItem label="Chocolatey">
    ```powershell
    choco install vitals
    ```

    <Aside type="caution" title="În așteptarea moderării">
      Pachetul 1.0 așteaptă aprobarea moderatorilor Chocolatey; până atunci este listată doar o
      versiune preliminară veche, 0.9. Între timp, folosește una dintre celelalte variante.
    </Aside>

  </TabItem>
</Tabs>

## Telefon, ceas și televizor

Fiecare [versiune de pe GitHub](https://github.com/dragoscv/vitals/releases/latest) are trei fișiere
APK pentru Android: `Vitals_<versiune>_android.apk` pentru telefoane, `_wear.apk` pentru Wear OS și
`_tv.apk` pentru Android TV și Google TV. Fiecare monitorizează dispozitivul pe care rulează și poate
urmări PC-urile Windows asociate din rețeaua locală. Listările din Google Play urmează mai târziu.
