<CardGrid>
  <Card title="Honest numbers" icon="approve-check">
    A reading the hardware cannot report is shown as unknown, never as zero. A feature your
    privileges do not allow is greyed out with the reason, not a button that fails when clicked.
  </Card>
  <Card title="Why is my PC slow?" icon="magnifier">
    One click correlates CPU, disk, memory pressure, network and thermal throttling, then names the
    cause in plain language: a verdict, the culprits and a minute of chart you can copy into a bug
    report.
  </Card>
  <Card title="Processes with a risk model" icon="list-format">
    Grouped, searchable and steady under the pointer. End, suspend and resume state the actual
    consequence before you confirm, and processes that live for under a second are still recorded.
  </Card>
  <Card title="Performance, all of it" icon="laptop">
    CPU with a cell per logical processor, memory, GPU, every disk and network adapter, and a
    Thermals tab that also lists what it cannot measure and why.
  </Card>
  <Card title="Beyond the window" icon="puzzle">
    Your phone over the LAN, Prometheus, Home Assistant, a typed TypeScript SDK and a CLI, all fed
    by one sampler so they always agree.
  </Card>
  <Card title="Light on your machine" icon="rocket">
    The Windows sampler has a 30 ms-per-sample budget enforced in CI — at most about 3 % of one core
    at the one-second rate while visible — and it samples only every 20 seconds when hidden. A
    monitor that shows up as a top consumer in its own process list has failed at its job.
  </Card>
  <Card title="No telemetry" icon="information">
    No analytics, no crash reporting, no account. The only automatic request is an update check, and
    you can turn that off.
  </Card>
  <Card title="Open source" icon="github">
    MIT licensed. Every release carries a build attestation linking the installer to the exact
    commit and workflow that produced it.
  </Card>
</CardGrid>

## Install

<Tabs syncKey="install">
  <TabItem label="Microsoft Store">
    Get [Vitals: System Monitor](https://apps.microsoft.com/detail/9P95RK5VMGPJ) from the
    Microsoft Store. There is no SmartScreen warning and the Store keeps it up to date. The Store
    build leaves out the built-in updater, the Task Manager replacement and the optional sensors
    service.
  </TabItem>
  <TabItem label="winget">
    ```powershell
    winget install Vitals.Vitals
    ```
  </TabItem>
  <TabItem label="Scoop">
    ```powershell
    scoop bucket add vitals https://github.com/dragoscv/scoop-vitals
    scoop install vitals/vitals
    ```
  </TabItem>
  <TabItem label="Installer">
    Download [`Vitals_x64-setup.exe`](https://github.com/dragoscv/vitals/releases/latest/download/Vitals_x64-setup.exe)
    and run it. There is no wizard. Windows SmartScreen will warn you on first run because the
    builds are not signed with a commercial certificate. The
    [download page](/download/) explains why and how to verify the file yourself.
  </TabItem>
  <TabItem label="Chocolatey">
    ```powershell
    choco install vitals
    ```

    <Aside type="caution" title="Pending moderation">
      The 1.0 package is waiting for Chocolatey's moderators; until it is approved only an old 0.9
      pre-release is listed. Use one of the other options meanwhile.
    </Aside>

  </TabItem>
</Tabs>

## Phone, watch and TV

Every [GitHub release](https://github.com/dragoscv/vitals/releases/latest) carries three Android
APKs: `Vitals_<version>_android.apk` for phones, `_wear.apk` for Wear OS and `_tv.apk` for Android
and Google TV. Each monitors the device it runs on and can watch paired Windows PCs on your local
network. Google Play listings are coming later.
