# Vitals — fact sheet

Every statement here is taken from the repository (README.md, PRIVACY.md,
apps/android/README.md, apps/tizen/README.md and the store listings). If one
of those changes, change this file with it.

## English

**Vitals** — _See what your computer is actually doing._

A fast, native system monitor and task manager for Windows. Free and open
source (MIT). It answers "why is my PC slow?" in plain words, with
honest numbers: a reading the hardware cannot report is shown as unknown,
never as zero.

**Platforms**

- Windows 10/11 x64 — stable. Windows 11 ARM64 — preview.
- Android phone and Wear OS — native apps that monitor the device itself and,
  optionally, paired Windows PCs on the local network. APKs are attached to
  each GitHub release; Google Play listings come later.
- Google TV and Samsung TVs (Tizen) — watch the Windows PCs on your home
  network from the TV.
- macOS and Linux — not published, and no dated plans.

**What it does**

- A configurable dashboard with an attention panel that names the cause of a
  slowdown.
- "Why is my PC slow?" — one click correlates CPU, disk, memory pressure,
  network and thermal throttling and names the cause in plain language.
- Performance for CPU, memory, GPU, every disk and adapter, and thermals.
- Processes, network connections, startup apps, services, installed apps and
  disk storage with a reviewed clean-up.
- The same readings reach a tray icon, an always-on-top HUD, your phone over
  the LAN, Prometheus, Home Assistant, a TypeScript SDK and a CLI.

**Privacy**

- No telemetry, no analytics, no advertising, no accounts, no crash reporting.
  The developer receives no data.
- The only automatic connection is an update check to GitHub, which can be
  turned off (Settings → About). The Microsoft Store version makes no such
  request.
- Remote access (viewing the PC from a phone) is off until the user turns it on.
- On Android, the QR scanner (Google ML Kit) sends Google anonymous
  diagnostics about itself; nothing else leaves the device.

**Boilerplate (50 words)**

> Vitals is a free, open-source system monitor and task manager for Windows,
> with companion apps for Android, Wear OS and TVs. It explains in plain words
> why a computer is slow, never invents a number it cannot measure, and sends
> no telemetry. Download it from the Microsoft Store or GitHub.

## Română

**Vitals** — _Vezi ce face de fapt calculatorul tău._

Un monitor de sistem și manager de activități rapid și nativ pentru Windows.
Gratuit și open source (licența MIT). Îți spune pe înțeles
de ce îți merge greu PC-ul, cu cifre oneste: o valoare pe care hardware-ul nu o
raportează apare ca necunoscută, niciodată ca zero.

**Platforme**

- Windows 10/11 x64 — stabil. Windows 11 ARM64 — previzualizare.
- Telefon Android și Wear OS — aplicații native care monitorizează dispozitivul
  și, opțional, PC-urile Windows asociate din rețeaua locală. Fișierele APK
  sunt atașate fiecărei versiuni de pe GitHub; Google Play urmează mai târziu.
- Google TV și televizoare Samsung (Tizen) — urmărești de pe televizor
  PC-urile Windows din rețeaua de acasă.
- macOS și Linux — nepublicate și fără planuri datate.

**Ce face**

- Un panou configurabil, cu o zonă de atenție care numește cauza încetinirii.
- „De ce îmi merge greu PC-ul?” — un clic corelează procesorul, discul,
  presiunea pe memorie, rețeaua și limitarea termică și numește cauza pe
  înțelesul tuturor.
- Performanță pentru procesor, memorie, placa video, fiecare disc și adaptor,
  plus temperaturi.
- Procese, conexiuni de rețea, aplicații de pornire, servicii, aplicații
  instalate și spațiu pe disc, cu o curățare pe care o verifici înainte.
- Aceleași citiri ajung în pictograma din tray, într-un HUD mereu deasupra, pe
  telefon prin rețeaua locală, în Prometheus, Home Assistant, un SDK
  TypeScript și o linie de comandă.

**Confidențialitate**

- Fără telemetrie, fără analiză, fără reclame, fără conturi, fără rapoarte de
  erori. Dezvoltatorul nu primește nicio dată.
- Singura conexiune automată este verificarea actualizărilor pe GitHub, care se
  poate opri (Setări → Despre). Versiunea din Microsoft Store nu face această
  cerere.
- Accesul de la distanță (PC-ul văzut de pe telefon) este oprit până îl
  pornești.
- Pe Android, scanerul de coduri QR (Google ML Kit) trimite către Google
  diagnosticări anonime despre el însuși; nimic altceva nu pleacă de pe
  dispozitiv.
