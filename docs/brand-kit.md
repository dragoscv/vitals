# Brand kit

The Vitals brand kit is everything a person needs to show or write about
Vitals: the logo in motion, splash and installer art, animated icons, social
and store images, the brand book and a press kit. All of it is **generated**
from the brand source of truth — `brand/mark.mjs` (geometry, colour, motion)
and `brand/brand.json` (version, fonts, consumers) — so a change to the mark
reaches every file by re-running one script. Never edit a kit file by hand.

Kit version = `brand/brand.json` `version` (currently 1.1.0). Rules for using
the mark, palette and voice live in `brand/BRAND.md` and in the brand book.

## Regenerate

```powershell
# from the repo root; build.mjs first if mark.mjs changed
node brand/scripts/build.mjs
node brand/scripts/demo.mjs
node brand/scripts/kit.mjs                       # everything (~2 min)
node brand/scripts/kit.mjs --only=social,book    # a subset
```

Subsets: `motion`, `splash`, `icons`, `logos`, `social`, `book`, `press`.
`--fps=60` sets the video frame rate. Run `book` after the others so its
download list is complete, and `press` last (it zips what is on disk).

What it needs, none of it new:

| Tool           | From                                                                                                 | Used for                                    |
| -------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------- |
| `sharp`        | root devDependency (already used by `build.mjs`)                                                     | PNG/BMP rasters                             |
| Chromium       | `@playwright/test` resolved from `apps/desktop` (`npx playwright install chromium` there if missing) | video frames, social images, brand book PDF |
| `ffmpeg`       | on `PATH` (libx264, libvpx-vp9, gif)                                                                 | MP4, GIF, WebM                              |
| Inter Variable | `brand/fonts/InterVariable.woff2` (OFL-1.1, `brand/OFL-Inter.txt`)                                   | text in social art and the book             |

Without ffmpeg the script still writes the animated SVG and Lottie files and
leaves the PNG frames in `.copilot-tmp/kit-frames/<motion>-<bg>-<fps>/`. To
encode one by hand:

```powershell
ffmpeg -framerate 60 -i .copilot-tmp/kit-frames/reveal-dark-60/f%04d.png -c:v libx264 -crf 22 -pix_fmt yuv420p -movflags +faststart brand/motion/vitals-reveal-dark.mp4
```

The script lives in `brand/scripts/kit.mjs` with helpers in
`brand/scripts/kit/` (`motion.mjs` keyframes + pose functions, `lottie.mjs`,
`social.mjs`, `splash.mjs`, `book.mjs`, `colour.mjs` WCAG maths, `zip.mjs`).

## Motion

The kit reuses the app's motion vocabulary (`packages/ui/src/styles/brand.css`,
generated by `build.mjs` from the same `motion` tokens) so the files and the
product agree. Only transform, opacity and stroke-dashoffset animate.

| Motion     | What it says                                               | Length      | App equivalent                  |
| ---------- | ---------------------------------------------------------- | ----------- | ------------------------------- |
| `reveal`   | tile settles (scale 0.9 → 1), line draws, glyph lifts once | 1.6 s, once | `intro` + `success`             |
| `pulse`    | glyph lifts and a lime highlight passes once, then rests   | 2.4 s loop  | `success` + one `thinking` pass |
| `thinking` | a lime highlight travels the dimmed line                   | 1.6 s loop  | `thinking` (scans, benchmarks)  |
| `loader`   | the bare line draws in and out, `currentColor`             | 1.6 s loop  | — (inline spinner)              |
| `alert`    | three horizontal nudges, then rest                         | 2.2 s loop  | `error`                         |

Each motion ships as:

| File                                       | Format                                    | Notes                                                                                            |
| ------------------------------------------ | ----------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `brand/motion/vitals-<m>.svg`              | animated SVG, CSS keyframes inside        | `prefers-reduced-motion: reduce` and print show the final frame; thinking keeps a static trace   |
| `brand/motion/vitals-<m>.json`             | Lottie (bodymovin 5.7, 60 fps, 512 × 512) | shape layers, trim paths, gradient fill only — no expressions or mattes; validated on generation |
| `brand/motion/vitals-<m>-{dark,light}.mp4` | H.264, 720 × 720                          | night `#0a1a10` / paper `#f1f7f2` background                                                     |
| `brand/motion/vitals-<m>-{dark,light}.gif` | GIF, 360 × 360, 30 fps, 96 colours        | for READMEs and chat                                                                             |
| `brand/motion/vitals-<m>.webm`             | VP9 with alpha, 720 × 720, 30 fps         | transparent; overlay on any background                                                           |

Easing tokens: `logo.ease` `cubic-bezier(0.22, 1, 0.36, 1)`, overshoot
`cubic-bezier(0.34, 1.56, 0.64, 1)`, sweep `cubic-bezier(0.45, 0, 0.55, 1)`.

## Animated icons

`brand/icons/animated/vitals-{idle,alert,thinking}-{16,24,32}.svg` — UI-size
animated SVGs for docs and the website. They use the optical variant for their
size (16 → micro, 24/32 → small), exactly as `BrandMark` does. idle = pulse,
alert = alert, thinking = thinking. All honour reduced motion.

| `brand/splash/nsis-sidebar-164x314.{bmp,png}`       | 164 × 314   | NSIS MUI2 welcome/finish sidebar                                      |
| `brand/splash/android/splash-icon-xxxhdpi.png`      | 1152 × 1152 | Android 12+ splash icon (288 dp at 4×), tile inside the 192 dp circle |

| `brand/splash/android/splash-icon-guide.png`        | 576 × 576   | review copy with the 192 dp mask drawn                                |
| `brand/splash/android/splash-icon.svg`              | 288 viewBox | vector source                                                         |
| `brand/splash/android/avd_vitals_splash.xml`        | 288 dp      | AnimatedVectorDrawable (intro, 900 ms)                                |

**Installer.** `apps/desktop/src-tauri/tauri.conf.json` currently sets no NSIS
images (`bundle.windows.nsis` has no `headerImage` / `sidebarImage`), so the
installer uses NSIS defaults. Tauri's NSIS options take a **150 × 57** header
and a **164 × 314** sidebar, both BMP — the two `nsis-*` files are made to that
spec. Wiring them in is a separate change to `tauri.conf.json`
(`"headerImage"`, `"sidebarImage"`, paths relative to `src-tauri`).

**Android.** The AVD is a suggestion and is not used by `apps/android`. To
adopt it, copy it to `res/drawable/`, set `windowSplashScreenAnimatedIcon` to
it, `windowSplashScreenBackground` to `#0a1a10` and
`windowSplashScreenAnimationDuration` to 900.

**Desktop app splash.** The in-app splash is the inline block in
`apps/desktop/index.html`, generated by `build.mjs` — the kit does not replace it.

## Social and store images

Rendered by Chromium from HTML templates with the embedded Inter, so Romanian
diacritics (ș ț ă î â) render correctly; the script fails if the font does not
cover the copy. Copy comes from `brand/BRAND.md` (marketing line) and the
existing site/store wording — no new claims.

| File                                             | Size        | Use                                                           |
| ------------------------------------------------ | ----------- | ------------------------------------------------------------- |
| `brand/social/og-1200x630-{en,ro}.png`           | 1200 × 630  | Open Graph / link previews                                    |
| `brand/social/x-1600x900-{en,ro}.png`            | 1600 × 900  | X / Twitter post image                                        |

## Brand book

- `brand/book/index.html` — one self-contained page: logo and lockups, optical
  sizes, clear space and minimum sizes, misuse, palette (hex + OKLCH),
  contrast table computed from `brand/contrast-pairs.json` (WCAG 2.2 AA),
  typography with the Romanian glyph check, motion (live animated SVGs and the
  timing/easing tokens), voice and tone (the EN/RO table from `BRAND.md`) and
  the downloads list.
- `brand/book/vitals-brand-book.pdf` — the same page, A4, via Chromium.

## Press kit

`brand/dist/vitals-press-kit-<version>.zip` bundles: `logo/` (all SVGs, PNG
mark and lockups at 512/1024/2048, Inter licence), `motion/`,
`icons/animated/`, `splash/`, `social/`, `screenshots/` (from
`packaging/msix/listing/screenshots`), `fact-sheet.md`
(`brand/press/fact-sheet.md`, EN + RO, every claim sourced from the repo),
`vitals-brand-book.pdf` and `brand-book.html`.

`brand/dist/` is git-ignored (`.gitignore` → `dist/`), so the ZIP is a build
output: regenerate it, then attach it to a release or upload it to the site.

## Logo PNGs

`brand/logo/png/mark-{512,1024,2048}.png` and
`brand/logo/png/lockup-{light,dark}-{512,1024,2048}.png` (width in px,
transparent) for people who cannot use SVG. The SVG originals stay in
`brand/logo/` and come from `build.mjs`.
