# Questions for a lawyer

Owner decision D2 (2026-11-12) is "keep the Health page and declare it
everywhere". These are the eight questions the legal review of 2026-11-12
raised that a lawyer — not an agent — has to answer, kept in the repository so
the answers have somewhere to land. Each one names the surface whose wording
changes with the answer.

Status: **unanswered** (as of 2026-11-17). Nothing below is legal advice.

| #   | Question                                                                                                                                                                                                                                                                                                       | What turns on it                                                                                                                                                                                                                 |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Art. 9 GDPR:** when health data goes from the user's own vmui server to the user's own device through Vitals, is the developer a controller or processor at all, or is this purely household use (art. 2(2)(c))? What changes if the developer later hosts vmui?                                             | `PRIVACY.md` and the site privacy page: whether they must name a lawful basis and a controller, or state that the developer is not a controller for this path. Today they describe it as the user's own server.                  |
| 2   | **Codwen:** with sign-in, the device name and prompts reach a service the same developer runs. Should `PRIVACY.md` name the developer as controller for that service, or refer to a separate policy for it? Is "the developer receives no data" misleading under Legea 363/2007 (unfair commercial practices)? | The AI agents section of `PRIVACY.md`, the equivalent section of `apps/site/src/content/docs/privacy.md` (+ `ro/`), and the MS Store listing line that names the two opt-in connections.                                         |
| 3   | **LGPL-2.1+:** does embedding `PawnIO.Modules` through `include_bytes` in an MIT binary meet the relinking/replacement requirement (§6), given that the modules are separate blobs loaded by a third-party driver?                                                                                             | `THIRD_PARTY_NOTICES.md` and `scripts/bundle-sensors.ps1`: either document how a user replaces the module with a modified one, or load it from a file beside the exe instead of embedding it.                                    |
